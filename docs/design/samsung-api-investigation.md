# 삼성증권 접속 경로 추가 조사

조사일 2026-10-24. 공개 공식 자료만 검토했다. 로그인·계정 인증·시세/주문 API 호출·문의 전송은 하지 않았다. 검색 결과가 없다는 사실로 API 부재를 단정하지 않는다. 검색 색인에서 읽힌 본문과 직접 열기에 실패한 자료를 구분한다.

## 결론과 설계 반영

개인 개발자가 즉시 키를 발급받아 사용하는 **현재 공개 주문 API의 문서·신청 절차는 미확인**이다. 그러나 삼성증권 공식 주문 안내의 자체 주문 시스템 관련 경로와 코스콤의 과거 제휴 주문 사례가 있어, 삼성증권의 프로그램 주문 경로가 전혀 없다고 결론 내릴 수 없다. 개인 자격·현재 제공 여부·접속 프로토콜·비용은 확인되지 않았다.

사용자가 이용이 애매하면 제외해도 된다고 허용했으므로 삼성증권을 **1차 구현·출시 범위에서 제외**한다. 조사 결과와 문의 질문은 향후 확장 참고로 보관하며 지금의 필수 준비 작업으로 남기지 않는다. 지원 상태는 UNVERIFIED이며 향후 공식 명세·자격을 확보할 때 별도 확장한다. data-only·파일 import와 execution 지원은 별도 상태이며, 다른 기관에서 시세를 받는다고 삼성 계좌로 주문할 수 있는 것은 아니다.

SS01–SS04의 일부 직접 열기는 502/timeout이었으며, 공식 도메인 검색 색인에 노출된 본문을 검토했다. SS05 본문은 직접 열어 발행일과 사례를 확인했다. SS06 목록에 삼성 주문 명세가 보이지 않는다고 과거 서비스가 폐지되었다고 판단하지 않는다. 검색 중 나온 Samsung Galaxy Store/IAP·삼성SDS·삼성선물 자료는 삼성증권 개인 주식 주문 API의 근거로 채택하지 않았다.

## 가능한 경로의 판정

| 경로 | 현재 판정 | Omega에서의 취급 |
|---|---|---|
| 개인용 공개 주문 API | 문서/신청 경로 미확인 | live 실행 금지, endpoint·auth 방식을 추정해 채우지 않음 |
| 삼성증권 특화주문/자체 시스템 접속 | 공식 안내에 경로가 있음, 우리 이용 자격·현행 명세 미확인 | 제공 기관에 확인할 후보, 비용/계약 자동 승인 없음 |
| 코스콤 제휴 주문 | 과거 삼성 연동 사례 확인, 현재 계약·제공 범위 미확인 | 별도 제휴/중계 adapter 후보, 개인 무료 접근으로 간주하지 않음 |
| HTS 내장 전략/자동주문 | HTS 내부 기능 안내 확인 | 외부 주문 API와 구분, Omega 주문 경로로 채택하지 않음 |
| DDE/Excel·수동 export | 과거 데이터 교환 기능 확인 | 승인된 데이터 import 가능성만 별도 검토, 주문 권한 없음 |
| 웹 세션 재사용·화면 자동 클릭 | 공식 주문 인터페이스 아님 | 기본 실거래 경로에 넣지 않음 |

## 공식 문의에서 받아야 할 답

외부 문의는 전송하지 않았다. 아래 질문은 향후 문의 한 번으로 필요한 자료를 받을 수 있게 준비한 것이다.

1. 개인이 본인 국내 현금주식 계좌를 자체 Python 프로그램으로 주문·정정·취소하고 잔고/주문/개별 체결을 조회할 수 있는 승인된 API/SDK가 있는가? 공개 API, 특화주문, 제휴 경로 중 어느 범주인가?
2. 개인·개인사업자·법인별 신청 자격, 별도 심사·최소 거래/자산 조건, 이용료·회선료·시세료, 개발/테스트 환경 조건은 무엇인가?
3. 현행 신청서·이용약관·기술 명세·샘플·변경 공지 URL과 담당 부서를 안내받을 수 있는가?
4. REST/WS/FIX/전용 SDK 여부, Windows/Linux 및 64bit Python 지원, 전용선/VPN/IP 등록·인증서/토큰·세션 조건은 무엇인가?
5. client order ID·중복 제출 방지·결과 불명 주문 조회·체결 ID 범위·재접속 후 누락 복구·수동 거래 관측을 지원하는가?
6. 국내 현금주식의 KRX/NXT/SOR 구분, 주문 유형·거래 가능 세션, 계좌/IP/endpoint별 제한과 실시간 구독 한도는 무엇인가?
7. 데이터 로컬 축적·원본 export·파생 dataset/학습 사용·개인 여러 기기 조회가 허용되는 범위는 무엇인가?
8. 코스콤을 통한 삼성 계좌 주문을 현재 지원한다면 개인의 직접 신청이 가능한가, 제휴 기관만 가능한가? 현행 삼성 지원 상품·주문/조회 API 명세는 무엇인가?

삼성증권 문의 출발점은 공식 안내에 기재된 Family Center 1588-2323이며, 실제 특화주문/API 담당 부서 연결이 필요하다. 코스콤 연락 경로는 [현행 이용 절차](https://koscom.gitbook.io/open-api/how-to-use/devcenter)를 확인한다. 이 문의로 계약하거나 유료 서비스를 신청한 것은 아니다.

## 구현을 열기 위한 증거

SS-A: 현행 공식 이용 자격과 접근 수단 확보 → SS-B: 상품·권한별 capability/한도·order identity 명세 → SS-C: credential 없는 fixture/parser 검증 → SS-D: 별도 승인된 모의/조회 시험 → SS-E: 사용자 실거래 허용 및 실행/복구 검증. 현재는 SS-A 미완료다.

Windows 전용 SDK가 제공된다면 해당 gateway만 Windows adapter worker로 격리할 수 있다. 이것은 Linux에서 삼성 gateway 자체가 동작한다고 보장하는 설계가 아니다. 전용 중계 프로세스 도입 여부는 실제 API와 자격이 확인된 뒤 정한다.
